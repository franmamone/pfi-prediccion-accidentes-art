\anexo{Cronograma de Actividades}\label{anexo:cronograma}

\textbf{Abril de 2026.}
Se define la propuesta y el alcance: priorizaci\'on de visitas ART a nivel de establecimiento, modelo XGBoost y explicabilidad SHAP, con stack Python, .NET y React.

\textbf{Mayo de 2026.}
Se redactan el marco te\'orico y el estado del arte (matriz de siete antecedentes).
Se arma el repositorio LaTeX UADE.
Se entrega el 25\% a fin de mes.

\textbf{Junio de 2026.}
Se habilita el acceso de solo lectura a la BD core de la ART y se exploran esquemas, vol\'umenes y tablas de siniestros, n\'omina y prevenci\'on.
Se dise\~nan las primeras vistas SQL.
Arranca la encuesta en l\'{\i}nea a trabajadores.
Se cierra el empaque documental del 25\% (car\'atula, flags de entrega y este Gantt).

\textbf{Julio de 2026.}
Se consolida la vista ML y el panel universo (del orden de 35.500 establecimientos).
Se entrena y eval\'ua el XGBoost con horizonte trimestral, se calcula SHAP y se compara el ranking con las visitas reales.
Se construye el prototipo local: BD operativa, API REST y frontend React (ranking, ficha, agenda y estad\'isticas), con snapshots de anal\'{\i}tica hist\'orica.
Se realizan las entrevistas a Adri\'an El\'{\i}as (8 de julio), Daniel Oscar (16 de julio) y Entrevistado~2 (23 de julio).
Se inicia la documentaci\'on de ingenier\'{\i}a del 50\%.

\textbf{Agosto de 2026.}
La aplicaci\'on pasa a llamarse Prevex y se cierra el circuito operativo (dossier, resumen generativo, lista de 1000 y horizonte solo trimestral).
Se sintetizan las personas a partir de la encuesta y las entrevistas a perfiles de ART.
Se documentan requerimientos, mockups, diagramas, competencias, modelo de datos y capturas de la interfaz en ejecuci\'on.

\enc{\textbf{Octubre de 2026.}
La encuesta en l\'{\i}nea alcanza 248 respuestas v\'alidas (corte del 16 de octubre).
Se regeneran gr\'aficos y se actualizan el Anexo de encuesta y la interpretaci\'on en el Cap\'itulo~3.}
