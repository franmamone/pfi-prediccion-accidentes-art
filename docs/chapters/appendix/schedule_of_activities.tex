\anexo{Cronograma de Actividades}\label{anexo:cronograma}

\textbf{Abril de 2026.}
Se defini\'o la propuesta y el alcance: priorizaci\'on de visitas ART a nivel de establecimiento, modelo XGBoost y explicabilidad SHAP, con stack Python, .NET y React.

\textbf{Mayo de 2026.}
Se redactaron el marco te\'orico y el estado del arte (matriz de siete antecedentes).
Se arm\'o el repositorio LaTeX UADE.
Se entreg\'o el 25\% a fin de mes.

\textbf{Junio de 2026.}
Se habilit\'o el acceso de solo lectura a la BD core de la ART y se exploraron esquemas, vol\'umenes y tablas de siniestros, n\'omina y prevenci\'on.
Se dise\~naron las primeras vistas SQL.
Arranc\'o la encuesta en l\'{\i}nea a trabajadores.
Se cerr\'o el empaque documental del 25\% (car\'atula, flags de entrega y este Gantt).

\textbf{Julio de 2026.}
Se consolid\'o la vista ML y el panel universo (del orden de 35\,500 establecimientos).
Se entren\'o y evalu\'o el XGBoost con horizonte trimestral, se calcul\'o SHAP y se compar\'o el ranking con las visitas reales.
Se construy\'o el prototipo local: BD operativa, API REST y frontend React (ranking, ficha, agenda y estad\'isticas), con snapshots de anal\'{\i}tica hist\'orica.
Se hicieron las entrevistas a Adri\'an El\'{\i}as (8 de julio) y Diego Oviedo (23 de julio).
Se empez\'o la documentaci\'on de ingenier\'{\i}a del 50\%.

\textbf{Agosto de 2026.}
La aplicaci\'on pas\'o a llamarse Prevex y se cerr\'o el circuito operativo (dossier, resumen generativo, lista de 1000 y horizonte solo trimestral).
La encuesta qued\'o en 156 respuestas v\'alidas.
Se sintetizaron las personas a partir de la encuesta y las entrevistas.
Se documentaron requerimientos, mockups, diagramas, competencias, modelo de datos y capturas de la interfaz en ejecuci\'on.
