\chapter*{Abstract}

Prevex is a predictive prototype that prioritizes prevention visits for Argentine workers' compensation insurers (ART).
Using a tabular panel built from operational insurer data (claims, payroll and prevention records), an XGBoost model is trained with a quarterly horizon and an explainable ranking is produced with SHAP values.
The prototype includes a web application (.NET API and React frontend) for preventores, coordinators and administrators: operational list, establishment detail, visit schedule, statistics, a normative copiloto grounded in an SRT corpus, structured visit closure, assisted geographic assignment and MFA authentication.
User research (survey and interviews) guided the design.
On the 2025 holdout the model reaches a PR-AUC of~0.515 and 66.7\,\% recall at the F2 threshold; the top-1000 list achieves a mean monthly precision of~49.5\,\%.
The API is validated with automated tests (Coverlet line coverage of~95.14\,\% on the domain scope).
The document also covers data protection under Argentina's Law~25.326, a B2B business model (the ART pays) and a USD economic-viability analysis.
Full production cloud deployment is out of scope for the prototype, which is validated locally and designed for AWS Free Tier.
